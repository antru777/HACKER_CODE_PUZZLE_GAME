# Hacker Code Puzzle Game

## Project Description

Hacker Code Puzzle Game is a console-based Python puzzle game.

The player has to solve different programming-related puzzles to complete all 10 levels.

## Technologies Used

- Python
- VS Code

## Levels

1. Password Verification
2. Number Lock
3. Loop Counter
4. Function Lock
5. String Decryption
6. List Security
7. Set Security
8. Linear Search
9. Bubble Sort
10. Master Hacker

## Game Rules

- Player starts with 3 lives.
- Correct answer gives 10 points.
- Wrong answer removes 1 life.
- The player must complete all levels.
- The final level is the Master Hacker level.
